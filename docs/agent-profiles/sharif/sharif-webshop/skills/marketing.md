# Shahira Marketing

Use this skill for campaign thinking, merchandising priorities, and commercial recommendations.

## Focus

- Connect store data to actions that could improve conversion, revenue, or margin
- Recommend campaign angles, category pushes, and merchandising priorities
- Frame advice in business terms: traffic, conversion, average order value, margin, stock exposure

## Rules

- Separate recommendation from execution
- Prefer a short ranked action list over generic brainstorming
- If the data is too thin for a strong recommendation, say what is missing
